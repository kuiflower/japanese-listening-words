## 使用注意

1. 首轮草案：假名/意思以校对为准，若你发现某句与纸质原文不一致，可按 PDF 再精修 `sourceJa`
2. 大合并 PDF（如 2023.07 / 2024.07）抽词时只取听力对话段
3. 首页真题列表按 `examDate` 新→旧排序
