# 日语听力单词强化训练网站 — 产品需求框架

> 版本：v0.2（已根据确认项更新）  
> 形态：仅黑夜模式的 Web 应用（优先适配手机竖屏，桌面也可使用）  
> 定位：**不是做题/测验**，而是听音 + 看义的强化记忆工具  
> 首期级别：**仅 N2**

---

## 1. 一句话说明

把日语能力考试 **N2 听力**真题里的**高频词、固定句、复合词**整理成可连续听练的卡片流，帮助快速记住**读音**和**中文意思**。

---

## 2. 目标用户与场景

| 项目 | 说明 |
|------|------|
| 用户 | 备考 JLPT **N2** 听力的学习者 |
| 主场景 | 通勤/碎片时间，或睡前自动播放；反复听日文读音（可选中文跟读）并对照意思 |
| 成功标准 | 能不打断节奏刷完一套真题词汇；收藏薄弱项；睡前定时自动关停 |

---

## 3. 内容从哪来 &「高频」如何定义

你提供：**试卷 PDF + 答案/解析/听力原文 PDF（+ 可选整卷音频）** → 整理词条库，按「某年某月真题」归档。

### 3.1 抽取范围

| 来源 | 抽什么 |
|------|--------|
| **试卷听力题选项** | 选项里出现的、对解题有区分度的名词/动词/形容词/复合词等 |
| **听力原文** | 原句中的关键实词、固定说法、复合表达 |
| **外部历年经验** | 对照公开的 N2 听力高频场景词、解题关键词、固定搭配，优先保留「本套出现 ∩ 历年常考」 |

### 3.2「高频」判定（首期规则）

同时满足越多，越优先入库：

1. 出现在本套听力**选项**或**原文关键句**中  
2. 属于 N2 听力常见场景（生活 / 商务 / 天气 / 交通方位 / 态度语气等）  
3. 在外部历年资料中常被标为听力易考点或易混点  
4. 排除过基础的日常词（如单纯的「行く」「見る」），除非在固定句/复合结构里有记忆价值  

类型标签：`高频词` / `固定句` / `复合词`

### 3.3 词条字段

| 字段 | 说明 |
|------|------|
| 原文写法 | 汉字/假名混写 |
| 假名读音 | 读法 |
| 中文意思 | 简洁翻译 |
| 补充解释 | **尽量带：来源句子片段 + 该句中文意思**；可附用法/易混点 |
| 类型标签 | 高频词 / 固定句 / 复合词 |
| 关联题号 | 听力第几题（用于跳转） |
| 音频 | **首期用浏览器 TTS**（日文 + 可选中文）；优先选用系统可用的最佳日语/中文音色 |

### 3.4「所有单词」定义（已确认）

= 你已提供并完成抽取的**全部词条合集**（跨已导入真题）。  
随着你继续提供新套真题并抽取，合集自动变大。

## 5. 页面与功能

### 5.1 首页 — 真题列表

- **收藏单词** / **所有单词** 两大入口  
- **真题列表**：按套进入  
- 列表可显示词条数；支持「继续上次」

### 5.2 练词页

**展示区：**

1. 单词（汉字等原文）— 默认始终显示  
2. 假名 — 默认始终显示  
3. 中文意思  
4. 解释（来源句片段 + 中文）

**听写模式（首期要做，默认建议：开）：**

- 默认：**意思、解释被遮挡**（单词汉字 + 假名可见）  
- 点击遮挡区域 → 显示对应内容；可再点收回（或切到下一条时重新遮挡）  
- 设置里可开关听写模式  

**操作区：**

- **再听一遍**：按当前播放规则重播本条（日文，及若开启则含中文）  
- **收藏 / 取消收藏**

**底栏：**

| 按钮 | 行为 |
|------|------|
| 上一个 | 上一条；切条后按「手动/自动」规则播音 |
| 自动播放 / 暂停 | 见下方「播放模式」 |
| 下一个 | 下一条；**即使当前是手动模式，点击下一题仍先播放一遍当前（新）词** |

#### 播放模式（已确认细化）

| 模式 | 如何进入 | 行为 |
|------|----------|------|
| **自动模式** | 按下「自动播放」 | 按设置：播完 → 间隔 → 下一条；受「每词循环遍数」「中文跟读」「定时关闭」约束 |
| **手动模式** | 按下「暂停」即离开自动、进入手动 | 不自动跳转；**点「下一个 / 上一个」时，仍先播放一遍该词**（含设置中的中日循环规则） |

说明：暂停 ≠ 静音切词；暂停 = 停止自动连播，但手动切词仍会播音。

**其它体验：**

- 题号跳转、进度「3 / 120」、类型标签、「来源：第 N 题」  
- 桌面快捷键：← →、空格（自动/暂停切换）、R 再听、F 收藏  
- TTS：在可用音色中优先选质量较好的日语声（如 `Google 日本語` / 系统 `Kyoko` 等，按设备实际列表择优）；中文同理择优  

### 5.3 收藏单词页

- 与练词页同布局；收藏按钮为取消收藏  
- 空状态引导回列表  

### 5.4 设置页

| 设置项 | 选项 | 默认 |
|--------|------|------|
| 自动播放间隔 | 1.5s / 2s / 3s / 4s（一轮播完后再计） | 2s |
| 播放语速 | 0.8x / 1.0x / 1.2x | 1.0x |
| 每词循环遍数 | **1 遍 / 2 遍 / 3 遍**（指完整「日文[+中文]」循环次数） | 1 遍 |
| 播放中文翻译声音 | **开 / 关**（开：一遍日文后播一遍中文意思） | 开 |
| 循环方式 | 列表循环 / 到尾停止 | 列表循环 |
| 听写模式 | 开 / 关（意思与解释遮挡，点击显示） | 开 |
| 定时关闭（睡觉模式） | **关 / 15 分钟 / 30 分钟**（到时停止自动播放并提示） | 关 |
| 筛选类型 | 全部 / 仅词 / 仅固定句 / 仅复合词 | 全部 |
| 主题 | **仅黑夜**（无白天模式） | 黑夜 |

**单条播放顺序示例（中文开 + 循环 2 遍）：**  
日文 → 中文 → 日文 → 中文 →（若自动模式则间隔后下一条）

数据：设置与收藏存浏览器 localStorage，无需登录。

## 6. 核心交互流程

### A. 按真题刷词

首页 → 选套 → 听练 / 自动播放 / 题号跳转 / 收藏  

### B. 刷薄弱项

首页 → 收藏单词 → 仅在收藏池循环  

### C. 睡前自动听

设置定时 15/30 分钟 → 开自动播放 → 到时自动停止  

### D. 听写强化

听写模式开 → 只看汉字假名听音 → 点遮挡看意思/解释

## 8. 视觉原则

- 仅黑夜模式；手机优先大按钮  
- 信息层级：词 > 假名 > 意思 > 解释  
- 遮挡块在听写模式下要明显可点  
- 自动 / 暂停状态一眼可辨
